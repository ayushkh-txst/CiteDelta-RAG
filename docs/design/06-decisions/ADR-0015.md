# ADR-0015 — Provider-agnostic completions with a valid-time rate table

**Status:** Accepted · **Date:** 2026-08-11

## Context

Generation needs a hosted model. Ratchet compares vendors on a short
timetable, and the budget across three projects is under $80.

## Decision

A `Completions` port in `substrate.llm`, one real adapter, a recording fake.
Usage priced across four token buckets. Rates stored as date-ranged rows with
an exclusive upper bound.

## Alternatives

- **Call the SDK directly** — no seam for the comparison harness, no offline
  tests. Rejected.
- **Two vendor adapters today** — an abstraction four days ahead of its
  justification, built on the same day as the UI. Rejected.
- **Constants for rates** — the introductory Sonnet rate expires 2026-08-31,
  inside the project window. A dict of constants would be wrong before the
  work is done. Rejected.

## Consequences

**Positive.** Substrate depends on one vendor SDK, isolated to a single module.
Cost is visible per run. Historical costs stay priced at the rate in force
when they were incurred, because rates are time-scoped rows, not a snapshot.

**Negative.** A second adapter would be needed to exercise the port's
generality — acceptable, since the seam already exists and is tested against
the recording fake.
