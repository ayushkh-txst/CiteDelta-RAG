# ADR-0017 — Server-rendered UI, no build step

**Status:** Accepted · **Date:** 2026-08-11

## Context

The trace inspector does the demo work. This phase has no time for a frontend
toolchain, and the machine has no Node.

## Decision

Jinja templates rendered by FastAPI, HTMX vendored locally, one hand-written
stylesheet, SVG computed server-side.

## Alternatives

- **React/Vite** — a build step, a Node dependency, and a hydration story for a
  page that is mostly long-form text with one interactive control. Rejected.
- **A chart library for the ribbon** — a bundle to draw four rectangles.
  Rejected.

## Consequences

**Positive.** No build, no `node_modules`, deploy is one container. The ribbon
is unit-testable as arithmetic because its geometry is computed server-side
from dates the trace already has. No third-party runtime dependency on the
page, since HTMX is vendored.

**Negative.** Rich client interactivity would need rework — acceptable, since
the page has one interactive control.
