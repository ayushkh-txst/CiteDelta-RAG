# ADR-0021 — A second model, at a second price tier, through the same port

**Status:** Accepted · **Date:** 2026-08-13

## Context

Follow-up resolution is a short mechanical rewrite that runs before most
answers.

## Decision

`claude-haiku-4-5` via the existing `Completions` port, sharing one
`CostLedger` with the answer model.

## Alternatives

- **The answer model for both** — roughly doubles a follow-up's cost for no
  measurable gain. Rejected.
- **A hand-rolled coreference heuristic** — fails on exactly the
  date-extraction cases that make the feature worth having. Rejected.

## Consequences

A follow-up costs about $0.0008 more, roughly 3% of the answer it precedes.
**Nothing in `substrate/llm` changed to accommodate it** — the port and the
dated rate table absorbed a second model at a different tier unmodified,
which is the difference between a real abstraction and a decorative one.
The provider returns the dated alias `claude-haiku-4-5-20251001` for a
`claude-haiku-4-5` request, so the adapter prices by the model asked for
rather than the echo.
