# ADR-0022 — Verify the quote, not just the citation

**Status:** Accepted · **Date:** 2026-08-13

## Context

Citations were checked for existence, retrieval, and admissibility. Nothing
checked that the answer's words were actually in the source.

## Decision

The model returns a verbatim `quote` per citation. A fourth validator check
requires it to appear in the cited chunk, whitespace-normalised but
case-sensitive. Failure discards the whole answer, exactly like a fabricated
id. Separately, `out_of_scope` moves into the response schema because no
retrieval threshold separates scope from relevance (measured: an out-of-scope
query scored 0.0325 against a greeting's 0.0164).

## Alternatives

- **Fuzzy or case-insensitive matching** — starts a slope that ends at
  passing paraphrase, the exact failure being tested for. Rejected.
- **A scope threshold on the fused score** — measurably impossible; raising
  it past an out-of-scope query's 0.0325 would refuse real questions.
  Rejected.

## Consequences

The guarantee upgrades from *"the citation is real"* to *"the quote is real"*,
and the UI gets the exact span to bold. Case sensitivity may prove brittle; if
so, loosen it **with the eval number attached**, not by guess. Also fixed the
`citations_valid` grader, which was true by construction and reported 1.00
even with the guarantee removed; the grader now re-verifies each quote from
the outside, and both scorecards are published. The adversarial eval class
moved 0.30 → 0.40 — `out_of_scope` catches *"not about immigration at all"*
but not *"a malicious question about immigration"*, which remains open work.
