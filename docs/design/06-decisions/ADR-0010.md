# ADR-0010 — `hnswlib` as a test oracle, not a dependency

**Status:** Accepted · **Date:** 2026-08-09

## Context

Building the index *is* the project (`spec §0.1`), so the reference
implementation cannot be in the product. But "is recall 0.48 good?" is
unanswerable without a reference point — especially for the suspected-hard
random benchmark the spec warns about, where a correct implementation can
score below its kill threshold. The spec's kill criterion was "if HNSW isn't
converging, ship IVF-Flat"; "converging" needs a baseline.

## Decision

`hnswlib` is a **dev-only dependency** (`[dependency-groups].dev`), imported
nowhere by the `citedelta` package itself. It is run as a benchmark oracle,
the same role the brute-force scan plays for the lexical index, and the
comparison is committed as an artifact (`03-benchmarks.md` §Reference
cross-check), not as a required unit test.

## Consequences

**Positive.** Every HNSW result carries its reference counterpart, so a low
number is readable as "the data is hard" rather than a bug. On identical
random vectors this implementation matches or beats hnswlib (ef=128: 0.475 vs
0.436); on the real corpus the two are within 3 points — but only on the 8k
subsample, which is the scale at which this implementation's graph is still
fully connected. At the full 37,911-vector corpus they diverged sharply: the
0.88 ceiling and the 0.484 filtered number were construction defects in this
implementation (no connectivity guarantee — 5,400+ components at full scale),
not properties the reference shares (see ADR-0012). *(Update 2026-08-11: the
defect is fixed — orphan protection in `_insert` plus `_repair_connectivity`
keep layer-0 connected, so full-scale unfiltered recall is 0.983 (tie-aware,
ef=256) and filtered 0.995 at 1.91% selectivity.)*

**Negative.** Any number is only as good as the reference staying current; a
packaging change in hnswlib cannot break `make check` because the comparison
is deliberately not part of the test suite — a low-scoring benchmark run is a
signal to investigate, not a failing check.
